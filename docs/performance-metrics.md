# Performance Metrics

The final metric set will depend on the hardware and experiments.

## RF measurements

- received signal strength
- SNR
- detection probability

## Temporal sensing

- variation amplitude
- periodicity strength
- detection accuracy
- false-positive rate

## Spatial sensing

- direction estimation error
- localization error
- angular resolution

## Antenna

- gain
- efficiency
- radiation pattern
- bandwidth
- reconfiguration time
- isolation between states

## System

- processing latency
- control-loop response time
- detection range
- performance under obstruction
- power consumption
- total cost

These are candidate metrics, not measured results.
